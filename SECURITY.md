# Security Policy

## Reporting Security Issues

If you discover a security vulnerability in this repository, please report it responsibly.

### How to Report

1. **Do NOT** open a public issue for security vulnerabilities.
2. Email the maintainers directly with:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fixes (if any)

### Response Timeline

- We will acknowledge receipt within 3 business days.
- We will provide a detailed response within 10 business days.
- We will coordinate a fix and public disclosure timeline.

## Data Security

This repository contains only publicly available information about free certifications. We do not collect, store, or process personal data.

### Sensitive Information

Do NOT commit:
- API keys, tokens, or credentials
- Personal information (emails, addresses, phone numbers)
- Internal server details or infrastructure information
- Proprietary code or trade secrets

### Secure Development

- All contributions are reviewed before merging.
- Automated validation runs on all PRs.
- Dependencies are minimized and audited.

## Dependencies

This project uses minimal dependencies. Any new dependencies must be:
- Open source with a permissive license
- Justified in the PR description
- Approved by maintainers

## Updates

This security policy may be updated periodically. Check back for the latest version.
